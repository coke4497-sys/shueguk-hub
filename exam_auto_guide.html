지필 리포트, 시험지로 자동 생성

시험지와 정답지를 올리면 클로슈가 문항 분석과 총평 초안을 만들어 드립니다. 선생님은 초안을 확인하고 학생을 배정해 등록만 하시면 돼요.

1
시험지 올리기시험지·정답지(사진·PDF)를 올리고 초안 요청.
2
초안 기다리기몇 분에서 10분쯤 뒤 목록에 완료가 떠요.
3
확인하고 등록리포트 만들기 → 내용 확인 → 학생 배정 → 등록.

어디서 여나요

티쳐스 페이지 → 지필고사 리포트 → 지필고사 리포트 제작

제작 페이지를 열면 자동 생성과 수동 생성 두 카드가 나옵니다. 지금까지처럼 직접 입력하시려면 수동 생성을 누르시면 돼요.

1. 시험지 올리고 초안 요청하기

  1. 시험 기간 · 학교 · 학년 · 과목을 고릅니다. 고른 값으로 리포트 제목이 만들어져요(예: 26-2-중간-화정고1-공통국어2).
  2. 시험지를 올립니다. 사진이나 PDF 모두 되고, 여러 장을 한 번에 고를 수 있습니다. 페이지 순서대로 골라 주세요.
  3. 정답지를 올립니다. 정답지가 있으면 문항 분석과 난이도 판단이 훨씬 정확해져요.
  4. 시험 범위는 내신대비 피드백에 적어 둔 범위가 자동으로 채워집니다. 없으면 알고 있는 만큼 직접 적어 주세요.
  5. 참고 메모에 변별 문항, 학생들이 어려워한 부분, 총평에 꼭 넣을 말을 적으면 총평 초안에 반영됩니다.
  6. 초안 요청을 누릅니다. 창을 닫아도 괜찮아요.

파일 하나에 20MB까지 올릴 수 있습니다.

2. 자동 생성 목록 보기

제작 페이지 첫 화면 아래 '자동 생성 목록'에서 요청 상태를 확인합니다. 만드는 중인 요청이 있으면 20초마다 저절로 새로 고쳐져요.

상태뜻과 할 일
만드는 중클로슈가 초안을 만들고 있습니다. 한참 지나도 그대로면 다시 알리기를 눌러 주세요.
완료초안이 준비됐습니다. 리포트 만들기를 누르세요.
보류초안을 만들지 못했습니다. 아래에 이유가 적혀 있어요(예: 사진이 흐려 읽지 못함). 다시 찍어 새로 요청해 주세요.
리포트 등록됨이 초안으로 리포트를 이미 등록했습니다.

옮긴 글 보기로 시험지를 글로 옮긴 내용과 정답을, 원본 보기로 올린 사진·PDF를 언제든 다시 볼 수 있어요. 올린 파일은 지우지 않고 보관합니다.

3. 확인하고 등록하기

  1. 리포트 만들기를 누르면 입력 화면에 제목 · 시험 범위 · 문항 · 총평이 채워집니다.
  2. 화면 위 분홍 상자의 '확인할 점'부터 봐 주세요. 흐려서 읽지 못한 글자, 정답이 의심스러운 문항 등이 적혀 있어요.
  3. 문항(지문 묶음 · 영역 · 세부유형 · 난이도 · 문항 내용)과 총평을 확인하고 고칩니다.
  4. 학생 배정 칸을 직접 골라 주세요. 고르지 않으면 등록이 되지 않습니다. 다른 리포트에 배정한 학생이 잘못 넘어가지 않게 하려는 장치예요.
  5. 시트에 등록을 누르면 배정한 학생의 개별 페이지에 리포트가 보입니다.

사진 잘 찍는 요령

  • 한 장에 한 페이지씩, 종이가 화면에 꽉 차게 찍어 주세요.
  • 밝은 곳에서, 그림자와 반사광이 없게 찍으면 잘 읽혀요.
  • 기울지 않게 위에서 똑바로 찍어 주세요.
  • 스캔한 PDF가 있으면 PDF가 가장 좋습니다.

알아 두세요

초안은 AI가 만든 것입니다. 문항 분석과 총평을 등록 전에 반드시 확인하고 고쳐 주세요.

등록하기 전에는 학생에게 보이지 않습니다. 초안을 열어만 봐도 괜찮아요.

총평에는 시험지로 알 수 있는 내용만 들어갑니다. 학생 반응이나 점수 같은 내용은 참고 메모에 적어 주시거나 등록 전에 직접 더해 주세요.

불편한 점이나 고치고 싶은 것은 시간표 페이지의 [수정 요청]에 남겨 주세요.
