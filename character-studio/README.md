# 슈국 캐릭터 스튜디오

캐릭터(설명서 + 참고 이미지)를 수파베이스에 저장해 두고, 장면 설명만 적으면
챗GPT(gpt-image-1)가 같은 캐릭터로 그림을 그려 주는 **개인용 로컬 웹앱**.
파일 하나(`슈국_캐릭터_스튜디오.html`)를 더블클릭하면 열린다 — 서버·설치 불필요.

## 처음 설정 (한 번만)

1. **수파베이스에 표 만들기** — 새 프로젝트 권장(기존 프로젝트에 넣어도 `cs_` 접두라 안 섞임).
   SQL Editor에 `1_수파베이스_설치.sql` 전체를 붙여넣고 Run.
   → 표 3개(`cs_characters`·`cs_character_images`·`cs_scenes`) + 보관함 2개(`cs-refs`·`cs-scenes`).
2. **열쇠 3개 챙기기**
   - 수파베이스 Project Settings → API Keys: **Project URL**, **anon public 키**
   - [platform.openai.com/api-keys](https://platform.openai.com/api-keys): **챗GPT(오픈AI) API 키** (크레딧 충전 필요, gpt-image-1은 조직 인증(Verify Organization)을 요구할 수 있음)
3. **HTML에 열쇠 적기** — `슈국_캐릭터_스튜디오.html`을 메모장으로 열어 맨 위 `CONFIG`의
   따옴표 사이에 붙여넣고 저장. 건너뛰면 파일을 열 때 뜨는 창에 넣으면 된다
   (이 경우 브라우저를 껐다 켜면 다시 넣어야 함).
4. **더블클릭으로 열기.**

## 쓰는 법

- 처음 한 번: **캐릭터 관리** 탭 → 이름·캐릭터 설명서 저장 → 참고 이미지(원본·회전시트·표정시트) 올리기.
- 그 다음부터: **장면 만들기** 탭 → 상황 적고 [이 장면 그리기] → [이미지 다운로드].
- 화면 맨 위 띠의 **앞 5장**이 매번 자동으로 함께 전송된다 — 중요한 이미지를 위로 올려 둘 것.
- '그림 안에 글자를 넣지 않기'가 기본으로 켜져 있다 — 말풍선은 비워서 나오니 캔바에서 고운 바탕으로 대사를 얹는다.
- '챗GPT에 실제로 보내는 문장 보기'로 설명서가 어떻게 조립되는지 확인할 수 있다.
- 만든 장면은 자동으로 기록돼 아래 '최근 만든 장면'에서 다시 저장할 수 있다.

## 주의

- **열쇠를 적은 파일은 웹에 올리거나 다른 사람에게 파일째 보내지 말 것.**
  조교와 같이 쓰려면 열쇠 칸을 비운 채 전달하고 각자 넣게 한다.
- 저장소에 커밋된 이 파일의 CONFIG는 항상 빈 값이어야 한다 (GitHub Pages로 공개되는 저장소).
- 학원 운영 데이터(shueguk 수파베이스 프로젝트)와는 완전히 별개 — 새 프로젝트 사용을 권장.
